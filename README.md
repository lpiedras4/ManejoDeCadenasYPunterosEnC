# Ejercicio
Escribe un programa en C que:
✓ Solicite al usuario que introduzca su nombre.
✓ Utilice un puntero para recorrer la cadena del nombre y contar cuántas letras
tiene.
✓ Solicite al usuario que introduzca un saludo.
✓ Concatene el nombre del usuario con un saludo que diga "Hola, ".
✓ Muestre el saludo completo en la pantalla.
✓ Muestre cuántos caracteres tiene el nombre del usuario.
